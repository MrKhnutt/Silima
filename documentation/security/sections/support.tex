\section{Support and Security Reporting}

Silima is an independently developed and maintained
software project. Documentation and source code are
publicly available through the project's GitHub repository.

Users are encouraged to consult the available documentation
and source code when troubleshooting installation,
configuration, or application behavior.

\subsection{Issue Reporting}

Software bugs, feature requests, and general support
questions may be submitted through GitHub Issues:

\url{https://github.com/MrKhnutt/Silima/issues}

Reports should include sufficient information to
reproduce the problem, where applicable.

\subsection{Security Reporting}

Potential security vulnerabilities may also be reported
through the project's GitHub repository.

Sensitive vulnerability details should not be disclosed
publicly before they can be reviewed. Private vulnerability
reporting may be used where available.

\subsection{Support Availability}

Silima is maintained on a voluntary, best-effort basis.
Technical support, issue resolution, and software updates
are provided as development time and resources permit.

No guaranteed response times, resolution deadlines,
or service-level agreements are provided.
