
\section{External Software}

Silima uses external software for game execution and browser-based
interaction. All software required for game execution runs locally
on the host (teacher's) computer. Student devices require only a
standard web browser.

\subsection{RetroArch}

Silima uses RetroArch, an open-source emulation frontend, to execute
games. RetroArch operates as a separate application on the host
computer and communicates with Silima through its local network
controller interface.

RetroArch must be installed and configured on the host computer.
It is not required on student devices.

RetroArch does not require internet access or any internet-based
functionality to operate with Silima. Features such as Netplay,
online updates, and other external network services are not
required and may remain disabled.

Depending on the game, RetroArch may require additional emulation
cores, game files, or BIOS files. These resources are managed
separately by the host. Silima does not distribute RetroArch,
game software, or copyrighted game content.

RetroArch is not installed, updated, or modified by Silima.
Installation and configuration remain the responsibility of
the host or system administrator.

Additional information:
\url{https://www.retroarch.com}

\subsection{Web Browsers}

Students and administrators access Silima through a standard
web browser, such as Mozilla Firefox, Google Chrome, or
Microsoft Edge.

No browser extensions, plugins, or additional client-side
software are required.

An internet connection is not required. Devices need only
be able to communicate with the Silima host over the local
network.

\subsection{Optional Python Dependency}

Silima includes an optional Python script for processing
and optimizing SVG graphical assets used by the browser-based
interface.

Python and its associated libraries are required only when
executing this utility. They are not required for normal
gameplay or student participation.

The script executes locally on the host computer and does
not require internet access during normal execution.

\subsection{Software Licensing and Game Content}

Silima does not provide or distribute commercial games,
emulation BIOS files, or other third-party copyrighted
game content.

The host is responsible for obtaining and using any game
software in accordance with applicable licensing requirements
and institutional policies.

Additional information regarding game content, copyright,
and publisher policies is provided separately in
\texttt{FAIR-USE.pdf}.
