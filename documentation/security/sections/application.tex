\section{Application Information}

Silima is a self-hosted platform for collective networked gameplay,
with publicly available source code. It allows groups of users to
connect through a browser, vote on or submit controller inputs,
and interact with shared gameplay and educational content.

Silima is primarily written in Rust and JavaScript, both established
technologies used throughout modern computing. Rust is a memory-safe
systems programming language. U.S. cybersecurity agencies, including
CISA and the NSA, recommend memory-safe programming languages such as
Rust to reduce common software vulnerabilities. Rust is also used by
major technology companies, including NVIDIA, for security- and
performance-sensitive software.

JavaScript has been a standard part of web browsers since the
mid-1990s and is now supported by essentially every modern browser.
Silima uses it for browser-based user interfaces, relying on the
same standard web environment used by ordinary websites and
web applications.
