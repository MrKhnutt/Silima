\section{Updates and Maintenance}

Silima is actively maintained, with major updates generally
targeted approximately once per month. Release frequency
may vary depending on development priorities and
availability.

\subsection{Software Updates}

Silima does not automatically download, install, or apply
software updates. All updates must be manually obtained
and installed by the host or system administrator.

New versions are made available through the project's
GitHub repository:

\url{https://github.com/MrKhnutt/Silima}

Silima does not require an internet connection for
normal operation, and updates may be downloaded separately
and transferred to the host computer.

\subsection{Future Update Notifications}

A future version of Silima may include an optional
mechanism to notify administrators when a newer version
is available.

Such functionality would only check for update
availability. It would not automatically download,
install, or execute new software.

Automatic software updates are not planned.

Security-related fixes may be released independently of the normal development schedule when necessary.
